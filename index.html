Ewens Tree Lab

A FastAPI-powered interactive lab for Ewens, Uniform Recursive, and Plancherel Recursive tree models. The full app includes tree visualization, simulations, parameter scans, exports, and a Small-n Explorer.

View Source arXiv 2604.25877

Models

Ewens recursive, Uniform recursive, and Plancherel recursive tree generation.

Analysis

Theory comparison, batch simulation, parameter scanning, and Small-n enumeration.

Visualization

Tree layouts, zoom and pan, node lookup, subtree metrics, exports, and history.

Run the interactive app locally

GitHub Pages is static, while the lab computes through a Python API. Use the source repository to run the complete app.

python -m venv .venv .\.venv\Scripts\pip install -r requirements.txt npm install .\.venv\Scripts\python.exe -m uvicorn ewens_app.main:app --host 127.0.0.1 --port 8765
